AI & Digital Engineering

Environmental engineering professional combining field and management experience with AI-assisted software development. I use modern AI coding agents to turn day-to-day operational requirements — permits, inspections, monitoring, reporting, document control — into working, tested tools that project teams actually use. Domain knowledge decides what gets built and validates the output; AI accelerates the build.

Every system below started from a real problem on a live construction project, was specified against existing procedures and official document formats, and was reviewed and tested before staff relied on it.

Environmental Management Portal

Live

Single web portal for a railway project's environmental registers — permits, work inspection requests, monitoring records and daily activity.

Problem
Permit expiries, inspection requests and monitoring records sat in separate spreadsheets held by different staff, so renewals and open items were easy to miss.
Impact
One register the whole unit works from, with renewal alarms, filtered reporting and a complete audit trail of who changed what.
Web AppFirebaseFirestoreJavaScript

AI role Designed and built with AI coding agents; the register logic itself stays fully deterministic.

Construction Weather Alert System

Live

Site-specific rainfall forecasting and automatic rain alerts along a 21 km railway construction corridor.

Problem
City-level forecasts cannot tell a crew whether rain will reach a particular structure within the hour, so concreting and lifting decisions relied on guesswork.
Impact
Fixed daily forecast briefings plus escalating live rain alerts to the site group chat and crew phones, on a graded monitor → alert → evacuate ladder proven in real storm conditions.
Node.jsCloud RunScheduled JobsMessaging APIAutomated Tests

AI role A language model writes the plain-language briefing from the forecast data, with a deterministic fallback so alerts still send if the model is unavailable.

Submittal Close-Out Tracker

Live

Shared dashboard showing which technical submittals are still open, and with whom.

Problem
Pending document status lived in workbooks refreshed by hand, so the list was already stale by the time it was circulated.
Impact
Automatic twice-daily refresh from the source register, manual corrections that survive each sync, and a cross-check that catches superseded revisions. Used daily by QA/QC and engineering staff.
PythonFlaskCloud RunScheduled SyncAutomated Tests
